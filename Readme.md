# 🛒 ShopKaro

> **ShopKaro is the rebranded and rebuilt version of SkyMart.**

ShopKaro started as **SkyMart**, an e-commerce project where several features and ideas were explored and implemented during the initial development phase.

With V2, the project has been **rebranded from SkyMart to ShopKaro** and its architecture and feature set have been intentionally reworked to create a stronger foundation for a scalable full-stack e-commerce platform.

### Why the Rebuild?

The first version of SkyMart contained several features and experiments that were useful for exploring the product idea, but carrying everything directly into V2 would have made the new architecture harder to develop and maintain.

Therefore, several features from V1 were **intentionally removed from the current V2 release**.

This was not a loss of direction, but a deliberate decision to:

- Rework the application around a cleaner architecture
- Strengthen authentication and authorization
- Build a proper product management system
- Improve backend validation and security
- Establish a better foundation for future features
- Separate core functionality from experimental features
- Prepare the project for a more scalable marketplace architecture

The features removed from V1 are **not permanently abandoned**. They are planned to be redesigned and reintroduced in future versions once the new foundation is ready.
